# history

Everything about one file: position, remuneration, statutory steps, claims by class, assets, meetings and recent activity.

Run `node scripts/cases.mjs history <ref or company>`. Add `--json` when you need every field. Resolve the file, creditor or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Read this before any write or draft about the file.
