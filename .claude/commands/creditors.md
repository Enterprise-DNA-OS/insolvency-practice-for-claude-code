# creditors

One file's creditors: kind, what the company's records said, what each claimed and was admitted, and dividends paid.

Run `node scripts/cases.mjs creditors --appointment=<ref>`. Add `--json` when you need every field. Resolve the file, creditor or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Flag related parties and any claim well above the records.
