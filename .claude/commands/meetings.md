# meetings

Meetings called and held, with notice dates and outcomes.

Run `node scripts/cases.mjs meetings [--appointment=<ref>]`. Add `--json` when you need every field. Resolve the file, creditor or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Flag meetings this week and any not yet recorded as held after their date.
