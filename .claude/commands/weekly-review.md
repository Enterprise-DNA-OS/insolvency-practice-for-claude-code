# weekly-review

Write the Monday review from attention, the next 14 days of statutory steps and money held.

Run `node scripts/cases.mjs weekly-review`. Add `--json` when you need every field. Resolve the file, creditor or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Summarise in five lines: what is overdue, what is due this week, which meetings are coming, which files hold cash, who owns each. The full draft is in drafts/.
