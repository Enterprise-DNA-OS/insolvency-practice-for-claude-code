# remuneration

Remuneration approved, drawn and recorded as time on each file.

Run `node scripts/cases.mjs remuneration [--appointment=<ref>]`. Add `--json` when you need every field. Resolve the file, creditor or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Lead with any file over approval, then files with more time than approval (a further approval is needed before drawing it).
