# draft-dividend-notice

Draft the notice of intention to declare a dividend for one class. Written to drafts/, never sent.

Run `node scripts/cases.mjs draft-dividend-notice <ref> --class=<class>`. Add `--json` when you need every field. Resolve the file, creditor or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Check the last day for proofs against /notice-dividend before handing it over. In Australia the prescribed form is Form 547 (Form 548 for a final dividend).
