# documents

Run `npm run docs`, or `npm run docs -- receipts-and-payments` for one kind, or `npm run docs -- receipts-and-payments <id-prefix>` for one file. Files land in `docs-out/`. Change the firm name, colours and logo in `brand.json`. These are working papers for the practitioner to check and sign off; nothing is lodged or sent.
