# draft-creditor-update

Draft an update to creditors on one file: realisations, claims by class, the next statutory steps. Written to drafts/, never sent.

Run `node scripts/cases.mjs draft-creditor-update <ref>`. Add `--json` when you need every field. Resolve the file, creditor or asset by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Fill the bracketed lines with the practitioner. It is a starting point for the statutory report, not the report itself.
